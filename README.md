# MACHINE_LEARNING_FJSP
FJSP for Machine Learning Course

Code for the IT8105 Assessment 2 report: *Latent Space Search for Flexible Job Shop Scheduling Using a Conditional Variational Autoencoder* (Willian Yoshio Iwamoto, Student ID 20251308).

The project trains one CVAE per Brandimarte instance (mk01-mk10) on solutions generated by a genetic algorithm, then searches its latent space with Differential Evolution and CMA-ES. Results are compared with random sampling, dispatching rules (FIFO, MWKR, SPT) and the genetic algorithm.

## How to run

All code is in `Machine Learning_Assessment 2.ipynb`. Open it in Jupyter from this folder and run the cells in order, Task 1 to Task 7, in one session. The notebook reads its inputs from this same folder, so the files below must stay where they are.

| Task | Content |
|---|---|
| 1 | Solution representation (OS and MS vectors) |
| 2 | Genetic algorithm and training corpus |
| 3 | CVAE with feasibility-preserving decoder |
| 4 | Latent space search (random, DE, CMA-ES) |
| 5 | Dispatching rules (FIFO, MWKR, SPT) |
| 6 | Latent space smoothness |
| 7 | Computation time |

## Files

- `brandimarte_dataset/`: instances mk01-mk10.
- `corpus/`: GA-generated training corpus for each instance (CSV).
- `cvae_mkXX_final_seedN.pt`: 30 trained CVAE checkpoints (10 instances x 3 model seeds).
- `task4_log.pkl`: stored results of the latent space search (Tables 4.1 and 4.2).
- `task6_log.pkl`: stored results of the smoothness analysis (Table 4.3).
- `timing_ga_training_v2.csv`, `timing_search_v2.csv`: computation times (Table 4.2).

## Notes

- The long-running steps are commented out so that running all cells does not overwrite the stored results: corpus generation (Task 2), CVAE training (Task 3), the search (Task 4), the smoothness analysis (Task 6) and the GA and training timing (Task 7, Part 1). Each one takes from several minutes to hours.
- Task 4 and Task 6 skip instances already stored in `task4_log.pkl` and `task6_log.pkl`. To rerun them, delete the corresponding file and uncomment the block.
- Re-running the Task 3 block retrains all 30 models and overwrites the checkpoints.
- Seeds are fixed (GA: 0-4, models: 0-2, search: 0-4; budget of 3,000 evaluations, condition c = 0). Small numerical differences may appear across machines and library versions.
- Libraries: Python 3, NumPy, SciPy, PyTorch and cma.
